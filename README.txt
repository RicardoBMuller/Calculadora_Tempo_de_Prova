FCC - Calculadora de duração de provas

VERSÃO SIMPLIFICADA

Agora existem somente dois dados para o cálculo:
1. Horário de Início
2. Duração da prova (HH:MM)

Exemplo:
Horário de Início: 10:08
Duração: 00:50
Encerramento: 10:58
